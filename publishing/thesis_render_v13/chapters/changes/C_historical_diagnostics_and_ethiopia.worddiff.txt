{+**Coverage rule and spatial assignment.** The first row states a rule, not a result. For each cluster and year, the extraction computes the exact area of overlap between a disk of the stated radius and each raster pixel, after projecting the pixel's corners into a local azimuthal equidistant projection (Section<nbsp>3.6). Pixels outside the raster, NoData pixels and values outside 0–100 are excluded from the valid area; they are never set to zero, and the buffer mean is taken over the valid area only. An annual value counts as complete when the valid area is at least 1 − 10⁻³ of the buffer's total area (`scripts/historical_wash/10_spatial_extraction_v3.py`, `FULL_TOL`). A window is used only if every year it touches has a complete value within 2000–2017; nothing is extrapolated or filled. The primary buffer is 2<nbsp>km for urban and 5<nbsp>km for rural clusters. Partial-coverage values are kept only as a diagnostic status and enter none of the 291 stored models. The buffer is centred on the DHS-displaced cluster location, so it does not recover the true location. It is an area average of modelled coverage, not a population-weighted coverage estimate.+}

{+\par\endgroup+}
{+```+}

{+**Containing pixel.** This row replaces the buffer average with the value of the single pixel that contains the displaced cluster point. NoData gives a missing value, and no nearest-cell value is substituted. Because a valid value is needed only for that pixel, the eligible sample differs from the main one (N<nbsp>=<nbsp>23,642 against 23,018). The move from 1.03 to 0.68 therefore reflects both the assignment rule and the sample.+}

{+**Rural 10<nbsp>km.** Rural children are assigned the 10<nbsp>km buffer average; urban children keep the 2<nbsp>km primary buffer. The sample again differs (N<nbsp>=<nbsp>22,521).
