% into its build directory (that wrapper defines \ThesisRoot, loads the
% shared preamble, adds the shared bibliography and metadata).
%
% One document, one table of contents, one reference list (cited works
% only), continuous Arabic page numbers from the first main-text page to
% the declaration. Chapters are not merged as separate PDFs.
%
% Abstract placement is carried over from the superseded v6 build
% (abstract = first numbered page; REQUIREMENTS_CHECKLIST.md R-14).
% Page breaks between main-text chapters (R-15) were likewise carried
% over from v6 at first, but R-15 is documented there as a publishing
% choice, not an explicit university requirement, that "adds pages to
% the main-text count, so revisit if the 40-page maximum becomes
% tight" -- which it did at final assembly (54 pages before this
% change). Main-text chapters therefore flow continuously below
% (no \clearpage between abstract/ch01..ch07); each chapter still
% opens with its own numbered \section heading. The reference list and
% each appendix still start on their own page, since neither is part
% of the main-text page count this choice was made to fit.
% =====================================================================
