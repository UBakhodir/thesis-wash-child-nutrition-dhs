# 4. Empirical strategy

Throughout, $i$ indexes a child, $h$ the child's household, $c$ the child's DHS cluster, $r$ the child's administrative region (each cluster belongs to exactly one region), and $s$ a survey round (country). All specifications below are estimated and reported in this thesis as **associational**, not causal; none should be read, described, or cited elsewhere in this thesis as identifying a causal effect. None of the designs below is a panel, a difference-in-differences design, or an instrumental-variables design — these terms are not used anywhere in this thesis to describe a specification that is not what is actually estimated.

## 4.1 Baseline: household WASH, region fixed effects

$$Y_{ihcr} = \alpha + \beta_W\,\text{Water}_{ih} + \beta_S\,\text{Sanitation}_{ih} + X_i'\gamma + \delta_r + \varepsilon_{ihcr}$$

$\text{Water}_{ih}$ and $\text{Sanitation}_{ih}$ are the child's own household water and sanitation status, **entered together in the same model** — every household-WASH specification in this thesis estimates $\beta_W$ and $\beta_S$ jointly, mutually adjusted for each other, never one at a time; $X_i$ is the covariate set described in Section 3.4; $\delta_r$ is a fixed effect for each of the 114 pooled administrative regions. Because $\delta_r$ absorbs any region-level average difference in the outcome, $\beta_W$ and $\beta_S$ are each identified from **within-region** variation in household WASH status only — comparing households inside the same administrative region to each other, net of the controls and of the other WASH measure — not from variation between regions, which the region fixed effect removes by construction. A region can contain many DHS clusters, so $\delta_r$ leaves room for clusters within the same region to still differ in local infrastructure, environment, or health-service access — characteristics plausibly correlated with both household WASH and child nutrition that this specification does not separately absorb. This motivates the cluster-fixed-effects specification below, which narrows the comparison further, to households within the same cluster.

## 4.2 Baseline: household WASH, DHS cluster fixed effects (the main household specification)

$$Y_{ihc} = \alpha_c + \beta_W\,\text{Water}_{ih} + \beta_S\,\text{Sanitation}_{ih} + X_i'\gamma + \varepsilon_{ihc}$$

As in Section 4.1, $\text{Water}_{ih}$ and $\text{Sanitation}_{ih}$ are entered together, mutually adjusted. $\alpha_c$ is a separate fixed effect for each DHS cluster. $\beta_W$ and $\beta_S$ are now identified from differences in household WASH status *among households within the same cluster*, conditional on the covariates and on each other; $\alpha_c$ absorbs anything shared by every household in a cluster simply by virtue of being in that cluster — local infrastructure, environment, market access — that a region fixed effect could not distinguish between clusters. It does not absorb differences *between* households within the same cluster: two neighbouring households can still differ in wealth, education, or unobserved behaviour in ways connected to both their own WASH status and their children's growth, which is why this specification remains associational rather than causal. One mechanical consequence: because every DHS cluster is entirely urban or entirely rural by DHS's own sampling design, urban/rural residence is automatically absorbed by $\alpha_c$ and cannot be separately estimated in this specification — this reflects how DHS clusters are sampled, not a specification error. **Wealth quintile is included in $X_i$ and is estimated, not omitted, in this specification**; cluster fixed effects absorb only what is constant within a cluster, and wealth varies across households within the same cluster (31.6% of clusters show within-cluster variation in own-water status and 50.6% in own-sanitation status — the variation that identifies $\beta_W$/$\beta_S$ in the first place; an identically-constructed check confirms comparable within-cluster variation in wealth), so there is no mechanism by which cluster fixed effects would remove wealth from this model, and none was observed to.

## 4.3 Baseline: community WASH, region fixed effects

$$Y_{ihcr} = \alpha + \beta_W\,\bar{C}^{water}_{-h,c} + \beta_S\,\bar{C}^{san}_{-h,c} + X_i'\gamma + \delta_r + \varepsilon_{ihcr}$$

$\bar{C}^{water}_{-h,c}$ and $\bar{C}^{san}_{-h,c}$ are the leave-one-out community water and sanitation coverage rates defined in Section 3.3, again **entered together and mutually adjusted** — including in the "minimally adjusted" stage of Table 5.2, which still adjusts each community measure for the other even though it adjusts for nothing else. Because these exposures are, by construction, properties of the cluster rather than of the individual child, $\beta_W$ and $\beta_S$ here are identified mainly by comparing *clusters* with different community coverage within the same administrative region, net of the same controls. As with the household region-fixed-effects model, unobserved differences between clusters inside the same region are not removed, so this is an associational estimate of a contextual exposure, not an estimate of a causal spillover effect.

**Why cluster fixed effects are not used for this exposure.** A natural question is whether community WASH could also be estimated with cluster fixed effects, matching the household specification. It can be, but the resulting estimate would not be informative, for a specific, verifiable reason. The leave-one-out community rate is itself a cluster-level quantity: within a given cluster, every child's own community value differs from every other child's only because a different single household happens to be excluded from each child's own calculation — a mechanical artefact of the leave-one-out construction. Measured directly in this data, the within-cluster standard deviation of this rate is approximately 0.007 (water) and 0.011 (sanitation), against an overall standard deviation of approximately 0.35 for both. A cluster fixed effect would therefore absorb nearly all of the genuine, substantive, between-cluster variation in community coverage, leaving a coefficient identified almost entirely by this small mechanical residual rather than by real differences in community environments. This is a fundamentally different situation from the historical extension's cluster-fixed-effects specification (Section 4.6), where a real time dimension — birth-cohort variation within the same cluster — gives cluster fixed effects genuine, non-mechanical within-cluster variation to work with. Cluster fixed effects are therefore appropriate for household WASH and for historical WASH, but not for current-round community WASH, and this is a design consequence of the leave-one-out construction itself, not an inconsistency in this thesis's approach.

## 4.4 Baseline: household and community WASH jointly, and current-age heterogeneity

$$Y_{ihcr} = \alpha + \beta_{HW}\,\text{Water}_{ih} + \beta_{HS}\,\text{Sanitation}_{ih} + \beta_{CW}\,\bar{C}^{water}_{-h,c} + \beta_{CS}\,\bar{C}^{san}_{-h,c} + X_i'\gamma + \delta_r + \varepsilon_{ihcr}$$

All four WASH terms — household water, household sanitation, community water, community sanitation — are entered **together, in one model**, each coefficient conditional on the other three. $\beta_{HW}$/$\beta_{HS}$ are the household associations conditional on surrounding community coverage and on each other, and $\beta_{CW}$/$\beta_{CS}$ are the community associations conditional on the household's own status and on each other. Because household and community water measures are fairly closely correlated, this specification is reported as a secondary decomposition, not a preferred model.

$$Y_i = \alpha + \beta_W\,\text{Water}_i + \beta_S\,\text{Sanitation}_i + \sum_{a \neq \text{ref}} \theta_a\,\text{AgeBand}_{ia} + \sum_{a \neq \text{ref}} \lambda^W_a\,(\text{Water}_i \times \text{AgeBand}_{ia}) + \sum_{a \neq \text{ref}} \lambda^S_a\,(\text{Sanitation}_i \times \text{AgeBand}_{ia}) + X_i'\gamma + \text{FE} + \varepsilon_i$$

Water and sanitation, and both of their full interaction blocks, are entered **together in one model**, exactly as in every other household specification in this thesis. $\text{AgeBand}_{ia}$ are six current-age bands in completed months — 0–5, 6–11, 12–23, 24–35, 36–47, 48–59 — replacing the continuous age control used elsewhere, with **12–23 months as the reference band**, fixed before any heterogeneity result was examined. Each of the other five bands therefore contributes one $\theta_a$ main-effect dummy and one interaction term per exposure ($\lambda^W_a$, $\lambda^S_a$), ten interaction terms in total. Three joint Wald tests are reported per outcome and fixed-effect structure: a water-specific test ($H_0: \lambda^W_a = 0 \ \forall a$, 5 restrictions), a sanitation-specific test (5 restrictions), and a combined test of all ten interaction terms jointly (10 restrictions) — each referred to a $\chi^2$ distribution with its stated degrees of freedom, not an $F$ distribution. The $\lambda^W_a$/$\lambda^S_a$ terms test whether the association between *survey-date* WASH and nutritional outcomes differs across children's *current* ages. This is a heterogeneity test on the existing cross-sectional design (Section 1.2), not a reconstruction of what WASH conditions an older child actually experienced during their own infancy, and it is kept conceptually and terminologically distinct from the historical extension's exposure-timing design throughout this thesis.

## 4.5 Inference, weighting, and the pooled estimand

**Weighting.** For a model with estimation sample of size $N$ pooled across $M$ countries, every country is given equal total weight in the pooled regression. Both pipelines implement this with each child's weight computed as

$$w_i = \text{raw}_i \big/ \sum_{j \in \text{country}(i)} \text{raw}_j$$

so that each country's weights sum to exactly $1$ (equivalently, $N/M$ on average across countries), where $\text{raw}_i$ is the sample's own native sampling-weight field — `v005`-derived for the baseline (Section 3.4), `PERWEIGHT` for the historical extension (Section 3.8), never the same field for both — computed within that model's own final estimation sample, after all exclusions actually applied to that sample (including singleton-cluster removal for the historical pipeline specifically — see below; the baseline pipeline applies no singleton-cluster removal step). The historical pipeline's own implementation (`scripts/historical_wash/16_estimate_preliminary.py`) additionally multiplies this by the constant $N/M$, so that each country's weights sum to exactly $N/M$ rather than $1$; the baseline pipeline's implementation (`build_temporary_pooled_weight()` in `scripts/dhs_harmonization/11_main_regressions.py`, reused by the household-model script) does not include this additional constant. This difference has **no effect on any reported coefficient, standard error, confidence interval, or p-value**: $N/M$ is the same constant for every observation in a given model regardless of country, and weighted least squares together with its cluster-robust sandwich variance are both invariant to rescaling every observation's weight by one common constant (confirmed directly for this thesis, by refitting a model under both conventions and finding identical coefficients and standard errors to machine precision). The two pipelines' weighting conventions are therefore substantively identical — equal total country weight — differing only in a reporting-level normalisation constant that a reader comparing raw weight values across the two pipelines should not expect to match. ($M$ denotes the number of countries, deliberately a different symbol from $K$, the regressor count used below in the inference formula, so the two are never read as the same quantity.) **This equal-country-total weighting is an authorised, disclosed working choice, not a correction for a sampling design, and it does not, by itself, define the pooled coefficient as any particular simple average.** The actual estimand is the single common slope $\beta$ of one pooled weighted regression run jointly across all countries' observations at once — not a two-step procedure of estimating each country's own slope separately and then averaging those slopes. It is important to be precise about what the weighting scheme does and does not imply for that single pooled $\beta$. Equal country weight *totals* do **not** make the pooled common-slope coefficient the arithmetic mean of the country-specific coefficients: by the Frisch–Waugh–Lovell logic underlying any partialled-out regression coefficient, the pooled $\beta$ is a weighted average of each country's own residualized-exposure contribution, where the weight each country effectively receives depends jointly on its observation weights **and** on the weighted sum of its *squared* residual exposure after the fixed effects and controls are partialled out — not on its observation weight alone. A country with little residual within-cluster exposure variation therefore contributes comparatively little statistical information to the slope even at an equal weight total. This thesis does not present a fully worked exact decomposition of the pooled coefficient into country-specific variance-weighted shares here; the statement above is the qualitative mechanism, illustrated with the actual numbers below, not a formal proof that the 0.58-versus-1.03 gap is explained by this mechanism alone to the exclusion of any other difference between the country-specific and pooled specifications. This thesis's own historical pooled water–HAZ estimate illustrates the point concretely, though as a documented empirical pattern, not as a claim that this specific ratio has been formally decomposed into exact variance-weighted shares: the simple unweighted average of the three established-date countries' own coefficients is 0.58, while the actual pooled coefficient is 1.03 (Section 5.6) — a pattern consistent with Kenya's residual exposure variation after controls (0.20 percentage points) being roughly a third of Nigeria's (0.65) and under half of Ghana's (0.46), so that Kenya's imprecise, negative country-specific estimate would be expected to receive comparatively little weight in the pooled slope despite its equal weight total. Every pooled coefficient in this thesis is reported alongside its country-specific components and each country's residual exposure variation, so a reader can see which countries actually drive a pooled result rather than inferring equal influence from the weighting description.

**Estimator and inference, stated separately for each pipeline because they are not identical.** Household- and historical-model cluster fixed effects are both implemented as weighted within-cluster demeaning, exactly equivalent to weighted least squares with a full set of cluster dummy variables, and both use the cluster-robust CRV1 sandwich estimator, clustered on the same DHS-PSU grouping used for the fixed effect, with the small-sample correction $c = \frac{G}{G-1}\times\frac{N-1}{N-K}$, where $G$ is the number of clusters and $K$ (a different symbol from $M$ above) counts only the non-fixed-effect regressors retained (the project's adjudicated convention when the fixed-effect grouping and the clustering grouping are the same variable). **The two pipelines differ, however, in the reference distribution actually used for confidence intervals and p-values, and this thesis describes each as implemented, rather than applying one description to both.** The historical pipeline (`scripts/historical_wash/16_estimate_preliminary.py`) explicitly uses the Student *t*-distribution with $G-1$ degrees of freedom for its confidence intervals and p-values (confirmed directly from its source and its stored output). The baseline pipeline (`scripts/dhs_harmonization/14_household_community_wash_models.py`'s `statsmodels` calls) does **not** select *t* inference: its executed `run_log.txt` records `use_t: False` for the primary cluster-fixed-effects fits, and the baseline's stored p-values and confidence intervals match a **normal (z)** reference distribution computed directly from the stored coefficient and standard error, not a *t*(*G*−1) computation — confirmed by independent recomputation (for the household water–HAZ cell, the normal-reference p-value matches the stored .0617391913770433 to more than ten decimal places, while the *t*(*G*−1) value, .0618052, does not; both happen to round to the same displayed .062, which is why a rounded-table check alone would miss this). This thesis's own baseline household cluster-fixed-effects model's primary p-values — water HAZ *p* = .062, sanitation HAZ *p* = .548 — are therefore normal-reference values, not *t*(*G*−1) values, under the project's adjudicated covariance convention described above; an alternative convention that additionally penalises degrees of freedom for the absorbed cluster dummies gives wider, still-available sensitivity p-values of .080 and .574 respectively (also normal-reference), reported as such wherever cited, never silently substituted for the primary values. This difference between the two pipelines' reference distributions is a documented implementation fact, not a choice this thesis makes case by case, and it is not changed here merely to make the two pipelines' descriptions match; a future, explicitly versioned update would be required to change either pipeline's actual inference convention.

**Singleton-cluster treatment, stated separately for each pipeline.** The historical pipeline explicitly drops clusters contributing only one observation to a given model's final estimation sample before estimation (`sizes >= 2` filter in `16_estimate_preliminary.py`) and reports the count dropped with every model, since a singleton cluster carries no within-cluster information and cannot contribute to identifying a cluster-fixed-effects coefficient. **The baseline pipeline's household- and community-model code (`14_household_community_wash_models.py`) contains no corresponding singleton-exclusion step** — this thesis does not assert that baseline singletons are dropped, or report a baseline singleton count, because no such step exists in the code that produced the baseline tables above. This is disclosed as a description gap, not assumed to be numerically inconsequential: sample size, cluster count, the finite-sample correction $c$ above, and the model-specific country-weight normalisation (Section 4.5) could all be affected by whether singleton clusters are present, and this thesis does not claim to have quantified that effect for the baseline models.

**Rank and identification are computational properties, not causal ones.** Every reported model's design matrix is checked for full column rank after the fixed-effects transformation, and any column found to carry no within-group variation (fully absorbed) is dropped and named explicitly rather than silently producing an unstable coefficient. This is a statement that the stated regression equation is computationally well defined and that its coefficient is the one the equation describes — it is not a statement that the equation identifies a causal parameter, and this thesis does not conflate the two.

## 4.6 Historical extension: cluster fixed effects with cohort controls

$$y_{ic} = \alpha_c + \beta\,E_{ic}(w, p) + \lambda\,\text{age}_{ic} + \gamma'X_{ic} + \delta_{s,b_{ic}} + \varepsilon_{ic}$$

$E_{ic}(w,p)$ is the annual-weighted IHME mean (product $p$, window $w$) assigned to child $i$ in cluster $c$, on the 0–100 percentage-point scale (Section 3.5–3.7); $\beta$ is reported per 1 and per 10 percentage points. $\alpha_c$ is the cluster fixed effect; $\delta_{s,b}$ is a survey-specific (country-specific) birth-year term — each country's own set of birth-year fixed effects, estimated relative to that country's own earliest observed birth year rather than one pooled reference year across all three countries. An early, incorrect independent-reconstruction attempt (Appendix B §B.2) used both a single pooled reference cell for the birth-year terms *and* omitted the child's own age-in-months control, together producing a materially different coefficient (1.385 vs. the correct 1.026). A dedicated diagnostic (`scripts/historical_wash/25_diagnose_birthyear_coding_and_age_control.py`) isolates these two changes rather than leaving them conflated, using a comparison that never uses the exposure variable itself to construct the test — residualizing a candidate control set against the exposure before checking whether it affects the exposure's own coefficient would be circular, and this diagnostic does not do that.

A single pooled reference year does, mechanically, change the raw design matrix — because each country's own observed birth-year range differs, a single shared reference year leaves Nigeria with an extra year dummy the country-local scheme does not have (13 raw columns vs. 12 for the country-local scheme). Compared directly after the cluster fixed effect's weighted within-cluster demeaning — before involving the exposure variable or any other covariate at all — the two schemes' birth-year blocks already span equal subspaces (rank 12 for both, and for their combination). The same equality holds after residualizing against the shared nuisance controls (age-in-months, maternal age, demographic dummies) alone, with the exposure variable explicitly excluded from that projection, checked separately with and without age-in-months. The mechanical reason is explicit: Nigeria's full set of own-year dummies (kept in full under the pooled scheme, since Nigeria has no births in the single shared reference year) sums exactly to Nigeria's own country indicator, which — because every cluster belongs to exactly one country — is fully absorbed by the cluster fixed effect, so the extra raw column adds no genuine dimension. Because the two schemes' nuisance specifications span equal subspaces, the exposure variable's own residualized values under either specification are, by construction, the same vector (confirmed directly, not merely inferred) — which by the Frisch–Waugh–Lovell theorem is a sufficient condition for its fitted coefficient to be identical between schemes. An explicit, independently computed partial-regression coefficient confirms this and matches the fitted model's own reported coefficient to within floating-point precision. The fitted results themselves confirm the exposure coefficient is identical between schemes at floating-point precision (absolute difference 6.7×10⁻¹⁶, holding the age-in-months control fixed — machine-precision noise, not an approximation). The age-in-months control, by contrast, fully accounts for the gap on its own: with it included, β = 1.0255531 (matching the stored 1.025553); without it, β = 1.3852855, which approximately reproduces the documented early-attempt value ("1.385") on this reconstruction — under either birth-year scheme. This diagnostic is a faithful reconstruction of the described early attempt, not a byte-for-byte rerun of its original, unpreserved code, so this thesis states it as evidence that the age-in-months omission explains the historical discrepancy on this reconstruction, not as certainty about exactly what that specific, no-longer-existing script did (Appendix B §B.2 gives the full result). $X_{ic}$ includes child sex, maternal age, maternal education, and marital status (wealth excluded from the main specification for the reason given in Section 3.8, not because cluster fixed effects absorb it).

**Why cluster fixed effects are appropriate here but not for current-round community WASH (Section 4.3).** The historical exposure $E_{ic}(w,p)$ varies not only across clusters but, genuinely, across birth cohorts *within* the same cluster — a child born in 2014 and a child born in 2017 in the same cluster can have experienced different modelled local WASH coverage during their own respective early-life windows. This is real temporal variation, not a mechanical construction artefact of the kind that rules out cluster fixed effects for the current-round leave-one-out community measure; the cluster-fixed-effects specification is therefore appropriate for the historical exposure, conditional on there being enough genuine within-cluster, cross-cohort variation for the fixed effect not to absorb nearly all of it — quantified, per model, as the residual exposure standard deviation after all controls (Section 5.6), which ranges from 0.20 to 0.88 percentage points depending on country and product. This range is modest relative to the 10-percentage-point scale conventionally used to report the coefficient (Section 5.6 states the ratio explicitly), and this thesis does not interpret a 10-point coefficient as describing an exposure contrast that is typically observed within a cluster.

Weighting follows the same equal-country-total formula as Section 4.5, with $M=3$ countries for the established-date pooled models (Ghana, Kenya, Nigeria), and inference uses the Student *t*(*G*−1) reference distribution the historical pipeline actually implements (Section 4.5 states precisely how this differs from the baseline pipeline's normal-reference inference). Model-specific samples are constructed independently for every window and product combination, and singleton clusters are dropped and counted by the historical pipeline's own explicit filtering step — this is a property of the historical pipeline's code specifically, not a claim that the baseline pipeline does the same (Section 4.5).
