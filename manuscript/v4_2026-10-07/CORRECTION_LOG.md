## What changed in the manuscript

One substantive correction, found by reading the primary source directly (full detail: `citation_map.md`):

| Problem in v3 | Correction in v4 |
|---|---|
| Literature Review §2.4 stated Donohue et al. (2023) found "community coverage carries explanatory relevance beyond a child's own household facilities," presented as a general finding. | Read the primary source in full (DHS Spatial Analysis Report 23, all relevant tables and discussion). The actual result is specific and mixed: significant only in Nigeria (adjusted OR = 0.97, modest), not significant in Zambia (the only two countries the report studies), with household sanitation not significant in either country's adjusted model. | Skoufias and Vinha (2026) described only generically ("formalising the intuition that..."), not with their actual finding. | Read the abstract directly. Their result is precise and asymmetric: no significant community-water externality, but a significant community-sanitation externality on fever/diarrhoea and height-for-age, varying by urban/rural. Added as a more precise, more useful parallel to this thesis's own asymmetric water/sanitation pattern. |
| Contribution section (§2.7) stated Donohue et al. and Skoufias and Vinha "call for" an early-life exposure-matching design this thesis attempts. | Neither source was found, on reading, to call for that specific extension — both examine current-round community exposure only. Corrected to state this gap is the thesis's own observation, not an attributed recommendation. |

## What was independently verified this pass, with no manuscript text requiring change

- **All 24 primary established-date historical model cells** (not just the 4 covered before this pass) independently reproduced via a second implementation (`scripts/historical_wash/21_validate_all_primary_cells.py`, generalising the prior single-cell script): coefficients match to ~1×10⁻¹⁴, N and G match exactly for all 24. The first run of this new script had its own bug (a clean 10× scaling error, caught immediately because N/G matched exactly but every coefficient was off by the same suspicious factor) — found and fixed before any claim was made on its output, documented in the script itself.
- **Spatial extraction's raw data layer** (raster reading, year-to-file mapping, coordinate handling, NoData/range detection) independently verified via `rasterio` (a different library from the project's own PIL-based extraction) against 48 justified test cases (full-coverage, boundary/low-valid-fraction, and NoData cases, across all three established-date countries and both products): 100% status agreement, exact (0.000000) value match on all 24 full-coverage cases. This verifies the data layer specifically, not the exact-polygon-overlap buffer-averaging algorithm itself, which remains unverified by a second implementation (stated, not glossed over).
- **IPUMS DDI/command-file agreement** re-checked directly from the raw `idhs_00002.xml`/`idhs_00002.do` files (not relying on an earlier session's record): GPSLAT/GPSLONG column positions agree exactly (311–320, 321–330) between the DDI and the Stata dictionary, and the DDI's own displacement-rule text matches what this project has documented throughout.
- **IHME raster metadata** re-checked directly from the raw GeoTIFF (opened from the original downloaded archive): CRS EPSG:4326, grid 6610×2123, pixel size 0.04° (consistent with the documented 0.041667°), NoData −999999 declared in the file's own metadata — all independently re-confirmed, not re-derived from an earlier inventory record.
- **Balk et al. (2004), Johnson, Jacob, and Brown (2013), Cumming and Cairncross (2016), Blom, Ortiz-Bobea, and Hoddinott (2022)**: each read directly (title/abstract/introduction level) and found to support the claim made about it in the manuscript without correction needed.
