\subsection*{B.2 Independent verification of the pooled historical model (Section 4.6, Section 5.6)}
\addcontentsline{toc}{subsection}{B.2 Independent verification of the pooled historical model (Section 4.6, Section 5.6)}

This thesis's own pipeline (\texttt{scripts/historical\_wash/16\_estimate\_preliminary.py}) estimates all 291 historical models using a hand-written weighted within-cluster demeaning estimator. A prior independent check (\texttt{scripts/historical\_wash/17\_validate\_estimates.py}) re-estimated four representative \textit{country-specific} cells (Ghana water HAZ weighted and unweighted; Ghana sanitation WAZ; Nigeria sanitation HAZ) with an explicit-dummy-variable statsmodels implementation, matching to 3×10⁻¹⁴.

This did not cover the pooled, multi-country model, which is the headline result of the historical extension. \texttt{scripts/historical\_wash/20\_validate\_pooled\_estimate.py}, written for this manuscript-preparation phase of the project, independently:

1. Rebuilds the estimation sample from the analysis-candidates stage directly (not from the stored, already-estimated model dataset), applying every filtering step explicitly and logging row counts (reproduced in Appendix A.3).
2. Estimates with \texttt{linearmodels.PanelOLS} --- a different software library from the project's own hand-written estimator --- using entity (cluster) fixed effects and clustered CRV1 standard errors.
3. Reports both the PRIMARY (\texttt{auto\_df=True}) and FULL\textbackslash\{\}\_DUMMY\textbackslash\{\}\_DF (\texttt{auto\_df=False}) conventions.
4. Estimates the unweighted counterpart on exactly the same final observations.

\textbf{First attempt and its correction, reported for transparency.} An initial run of this independent script used a single pooled reference birth-year cell (rather than a separate reference year per country) and omitted the child's own age-in-months as a linear control. This produced β per 10 points = 1.385 against the stored 1.026 --- a roughly 35\% discrepancy --- despite the sample size (N=23,018), cluster count (G=3,114), and exposure mean/SD matching the stored values exactly, which is what indicated a specification difference rather than a sample-construction error. After matching the documented design exactly (country-local-reference birth-year dummies; child age-in-months included), the independent estimate converged to:

\textbf{What this verification establishes, and what it does not.} It establishes that the reported pooled coefficient is computationally correct --- the number the documented specification, correctly implemented in a second, independent library, actually produces. It does not establish that the specification identifies a causal effect, and it does not place this one cell in a higher \textit{reporting} tier than its sibling historical models, all of which share the same unresolved documentation issues (Section 6; \texttt{docs/provenance/historical\_wash\_issue\_register\_v1\_2026-10-07.md}).
