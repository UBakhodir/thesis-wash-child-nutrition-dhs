## Phase 2 — Project evolution

Traced directly from code comments and documents, not inferred:

- **Original plan** (per `scripts/dhs_harmonization/09_admin_region.py`'s own docstring, "REGRESSION INTERPRETATION LOCK"): a multi-round panel-style identification strategy using a region-by-time grid (α_c) and a country×survey-year term (θ_kt) was the original design. This was **abandoned** because the assembled data has only one DHS round per country — explicitly documented in the code as "not feasible with the currently assembled data... not reconstructed here," with an explicit lock against describing `country_admin_region` as a panel identifier, a survey-year FE, or evidence of temporal identification.
- **Implemented design (original pipeline, Steps 00–13)**: cross-sectional, pooled + country-specific, community WASH (leave-one-out) with administrative-region FE (`country_admin_region`, confirmed 14+16+47+37=114 regions summing exactly as the manuscript states, independently verified from the admin-region construction script this pass), household WASH only as a binary robustness check.
- **Supervisor-driven addition #1** (`docs/empirical_strategy.md`; `scripts/dhs_harmonization/14_household_community_wash_models.py`): separating own-household WASH (cluster FE) from community WASH (region FE) as two distinct exposures with two distinct identification strategies, because the leave-one-out community measure has negligible within-cluster variation (documented and re-verified: ≈0.007–0.011 SD within cluster vs. ≈0.35 overall).
- **Supervisor-driven addition #2** (`manuscript/v11_2026-10-09/01_introduction.md` §1.2; `docs/literature_design_consistency.md` §8/§12, which flagged this as an then-open, blocking gap): the historical WASH extension, addressing the single-round design's inability to assign exposure near each child's own developmental window. This is now complete (291 models), reported throughout as preliminary with explicit documentation limitations, never as a panel, DiD, or IV design, and never implied to be preregistered (no preregistration exists or is claimed).
- **Abandoned/superseded approaches confirmed, by direct code/document inspection**: the original multi-round panel grid design (never implemented); DHSREGNA as Kenya's administrative geography (explicitly rejected in `09_admin_region.py` as an ecological malaria-zone variable, not administrative geography — confirmed absent from the manuscript); the pre-household-cluster-FE "Model 4 only" architecture described in the original `README.md` and `docs/thesis_design.md` (superseded by the household/community split).
- **Final roles, confirmed matching the current manuscript**: baseline = main current-round analysis (household + community, two distinct identification strategies); historical extension = a separate, explicitly bounded, preliminary sample-specific analysis, never compared to the baseline as an exposure-timing test (manuscript §6.2 states this explicitly and precisely).

**Verified**: the current manuscript (`01`–`08`, appendices) describes only the final, implemented design. No panel, DiD, or IV terminology is used anywhere in the canonical chapters (confirmed by direct reading across this and prior passes); no preregistration is claimed (the window choice is explicitly described as "not... preregistered," manuscript §6.4).
