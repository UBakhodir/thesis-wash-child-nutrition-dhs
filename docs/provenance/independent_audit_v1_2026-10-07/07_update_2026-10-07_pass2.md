## 2. Spatial-extraction independent verification (new; was previously unaddressed)

Script preserved at `scripts/historical_wash/22_validate_spatial_extraction_independent.py` (committed); output at `data/processed/spatial_extraction/independent_validation_20261007T174734Z/` (RESTRICTED, reproduces the figures below exactly).

Independently verified the **raw data layer** of the historical spatial extraction — raster reading, year-to-file mapping, coordinate handling, NoData detection, value-range validation — using `rasterio` (a different library from the project's own PIL-based `10_spatial_extraction_v3.py`), reading directly from the original downloaded IHME archives (`Percent.zip`, `Percent (2).zip`, confirmed present locally with matching file sizes/names to what `01_inventory_ihme_rasters.py` expects).

**Method**: for each of the three established-date countries (Ghana 2014, Kenya 2014, Nigeria 2018) and both products (W_IMP, S_IMP), selected 4 full-coverage cases, 2 missing/NoData cases, and 2 boundary cases (lowest valid_fraction in the stored primary-buffer output) — a justified, non-arbitrary sample covering the three failure modes most likely to reveal a coordinate, CRS, year-mapping, or NoData bug. Compared the independently-read containing-pixel value against the project's own stored `sensitivity_containing_pixel` value for the identical cluster/year/product.

**Result**: 48 cases checked; 100% status agreement (full vs. missing); on the 24 cases where both methods returned a valid value, the match was **exact** (0.000000 difference) in every case. IHME raster metadata (CRS EPSG:4326, grid 6610×2123, pixel size 0.04° ≈ the documented 0.041667°, NoData −999999) independently re-confirmed directly from the raw GeoTIFF's own embedded metadata, not from an inventory record.

**Explicit scope limit, stated precisely per this audit's own instruction**: this verifies the data layer the buffer-averaging method also depends on (same files, same coordinates, same NoData convention); it does **not** independently re-implement the exact-polygon-overlap buffer-averaging algorithm itself (the project's primary spatial-extraction method). That algorithm remains verified only by the project's own internal Monte Carlo self-check (`10_spatial_extraction_v3.py`'s `mc_reference()` function, 200,000-sample Monte Carlo, same codebase) — a real check, but not an independent one in the sense requested. This is recorded as still open.
