## Why this correction was needed

A chapter existing in this repository is not the same thing as a chapter having been reviewed by the person who asked to see it. Earlier public records (the supervisor-advice matrix and its addendum) tracked whether a design element was *implemented empirically*, which is a different question from whether a *specific request to send a document and receive feedback* has been acted on. This record exists so that "literature review: drafted" is never read as "literature review: supervisor-approved," and so that "introduction exists" is never read as "introduction sent."
